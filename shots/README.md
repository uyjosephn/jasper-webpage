## Taking them

On the phone: **Volume Up + Side button**, then AirDrop to the Mac and rename.

Use a device with a **6.7" display** (iPhone 15/16/17 Pro Max) — those are the
dimensions the App Store wants too, so the same set serves both purposes.

Make the data look real but not private: real *shapes* of numbers, nothing you
would mind a stranger reading. These end up on a public page and in an App
Store listing.

Turn on **Do Not Disturb** first so no notification banner lands in the shot.
