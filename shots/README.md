# Screenshots

The public page does **not** use photographs. Every screen it shows — the
forecast strip, the ledger, the amortisation schedule, goals, the progress
track — is rebuilt in HTML and CSS in `index.html` using the app's own colour
tokens. That keeps it sharp on any display, correct in both themes, readable by
a screen reader, and free of anybody's real figures.

This folder exists for the **App Store listing**, which does require real
captures and cannot use markup.

| File | Screen |
|---|---|
| `ledger.png`    | The Ledger, showing a mix of locked and planned entries |
| `dashboard.png` | The Dashboard — forecast months with their weather |
| `goals.png`     | Goals, with at least one part-way along |

## Taking them

On the phone: **Volume Up + Side button**, then AirDrop to the Mac and rename.

Use a device with a **6.7" display** (iPhone 15/16/17 Pro Max) — those are the
dimensions the App Store wants.

Make the data look real but not private: real *shapes* of numbers, nothing you
would mind a stranger reading. Change the figures first if your own are on
screen — these go in a public listing.

Turn on **Do Not Disturb** first so no notification banner lands in the shot.
